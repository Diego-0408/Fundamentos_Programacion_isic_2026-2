# Fundamentos_Programacion_isic_2026-2
# Fundamentos de Programación

Este repositorio se utilizara durante todo el primer semestre para guardar los trabajos y prácticas de la materia de **Fundamentos de Programación**.

Aquí iré subiendo los ejercicios, prácticas, diagramas y demás actividades que vaya realizando durante el curso. La idea es mantener todo organizado y, al mismo tiempo, tener un registro de lo que voy aprendiendo y mejorando conforme avance el semestre.

## Contenido

En este repositorio se podrán encontrar:

* Ejercicios de programación.
* Prácticas de la materia.
* Diagramas de flujo.
* Pseudocódigo.
* Documentación de las actividades.
* Otros trabajos realizados durante el semestre.

## Objetivo

El objetivo principal es aprender las bases de la programación y mejorar mi lógica para poder resolver diferentes problemas mediante algoritmos y código.

También quiero utilizar este repositorio para acostumbrarme a trabajar con Git y GitHub desde el inicio de la carrera y llevar un mejor control de mis actividades.

## Uso de Inteligencia Artificial

Durante el desarrollo de los proyectos y prácticas se hace uso de herramientas de Inteligencia Artificial exclusivamente como apoyo para la redacción, estructuración y formato de la documentación (tablas de casos de prueba, análisis IPO, ortografía y resúmenes). La lógica algorítmica, el diseño del pseudocódigo y los diagramas de flujo son desarrollados de forma propia.

## Organización

Las actividades estarán organizadas en diferentes carpetas para mantener el repositorio lo más ordenado posible.
