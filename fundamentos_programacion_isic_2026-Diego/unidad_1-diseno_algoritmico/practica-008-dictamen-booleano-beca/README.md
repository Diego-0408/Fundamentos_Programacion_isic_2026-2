## Resumen de la Solución
Este algoritmo se utiliza para determinar si un alumno puede recibir la beca, el algoritmo revisa de un solo golpe si cumple con las dos condiciones al mismo tiempo: tener el promedio mínimo y los créditos necesarios. Como ambos requisitos se combinan con un operador lógico, el programa no necesita dar rodeos ni tomar caminos con condicionales; simplemente valida la expresión y te dice directamente si el estudiante es elegible o no mediante un claro VERDADERO o FALSO.
