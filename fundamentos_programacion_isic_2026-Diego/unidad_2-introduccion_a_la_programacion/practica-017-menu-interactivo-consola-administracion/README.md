## Resumen de la Solución
Para garantizar la interacción inicial con la consola de red, el programa implementa un ciclo post-prueba Repetir - Hasta Que. Esto despliega obligatoriamente el menú al menos una vez y mantiene la ejecución activa procesando las opciones ingresadas hasta que el administrador selecciona explícitamente la opción 0 para salir.
